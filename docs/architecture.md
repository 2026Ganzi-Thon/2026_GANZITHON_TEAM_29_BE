# 백엔드 아키텍처

집중농장 백엔드는 별도 Spring Boot 서버 없이 Supabase를 중심으로 구성합니다.

## 구성 요소

- Supabase Auth: 이메일/비밀번호 인증과 세션 관리
- PostgreSQL: 도메인 데이터와 상태 전이
- RPC: 프론트엔드에 제공하는 업무 API
- RLS: 인증 사용자별 데이터 접근 제어
- Supabase Cron: 만료된 수확 대상 처리

프론트엔드는 별도 저장소에서 Supabase Auth SDK와 확정된 RPC를 호출합니다. 사용자 ID는 클라이언트 입력으로 신뢰하지 않고 DB 인증 컨텍스트에서 확인합니다.

## 담당 경계

- A (`Minimin0`): 인증 정책, 프로필, 작물 카탈로그, 추천, 농장 조회, 기록 조회, 통합과 배포
- B: 밭 생성, 집중 세션, 일시정지, 씨앗 보관, 수확, 휴식, 기록 초기화, 자동 수확 Cron

공용 설정, 마이그레이션, RLS, 권한과 API 계약은 공동 검토 대상입니다.
